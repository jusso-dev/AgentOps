# Demo Script

1. Open the dashboard and explain the portfolio goal.
2. Go to `/repositories`.
3. Import a public repository with `owner/repo` format.
4. Show imported repository counts.
5. Go to `/issues` and filter by state or type.
6. Click **Triage Issues** and review generated priority, risk, labels, next action, and implementation plan.
7. Go to `/changelog`.
8. Generate a changelog for the last seven days or a selected date range.
9. Show `AGENTS.md`, `CLAUDE.md`, `docs/mcp-setup.md`, and `.mcp/` examples.
10. Explain how deterministic agent modules can be replaced by a real LLM provider later.
